# Major System Map

Use this reference when teaching or validating the phonetic number system for `/pao-system`.

## Canonical Digit Sounds

| Digit | Consonant sounds | Memory cue |
|---|---|---|
| 0 | `s`, `z`, soft `c` | zero starts with z |
| 1 | `t`, `d`, hard `th` | one downstroke |
| 2 | `n` | two downstrokes |
| 3 | `m` | three downstrokes |
| 4 | `r` | last strong sound in four |
| 5 | `l` | Roman numeral L = 50 |
| 6 | `sh`, `ch`, `j`, soft `g` | script j resembles 6 |
| 7 | `k`, hard `g`, hard `c`, `q` | two sevens form a K |
| 8 | `f`, `v`, `ph` | handwritten f resembles 8 |
| 9 | `p`, `b` | mirror-image shapes |

The system maps **sounds**, not letters. `phone` begins with an `f` sound and therefore begins with 8. `giant` begins with a soft-g/j sound and therefore begins with 6.

## Filler Sounds

Vowels do not encode digits. The usual filler consonants `w`, `h`, and `y` also do not encode digits. Use them to make pronounceable words without changing the code.

Examples:

- `34` → `m-r` → Mary, mower.
- `17` → `t/d-k/g` → duck, Doug.
- `82` → `f/v-n` → fan, Vin.
- `06` → `s/z-sh/ch/j` → Sasha.

Do not count silent letters. Evaluate the pronunciation the user will actually recall.

## Teaching Sequence

1. Show the complete map once.
2. Explain two or three memory cues, then ask the user to make their own cue for any weak digit.
3. Drill all digits 0–9 in shuffled order. Ask for consonant sounds, not words.
4. Drill five new two-digit codes. Ask for the ordered sound pair.
5. Run a ten-item mixed quiz containing at least five single digits and five two-digit codes.
6. Pass only at 10/10. On a miss, explain the mapping cue, reshuffle, and quiz again; do not advance through partial mastery.

## Candidate Rules

A useful PAO person candidate must be:

- a concrete person or character the user can see mentally;
- immediately recognizable to this user;
- distinct from every other selected person;
- compatible with the code's ordered consonant sounds;
- capable of a signature physical action and object later.

Reject abstract peg words such as “more,” institutions, groups, and identities the user cannot picture. A stable personal association is more valuable than universal fame.

When generating candidates, provide 3–5 choices. Include the sound breakdown and let the user invent a better choice. Never silently assign a person.

## Common Confusions

- `c` is 0 when soft as in “ceiling,” and 7 when hard as in “cat.”
- `g` is 6 when soft as in “giant,” and 7 when hard as in “go.”
- `th` varies by Major System tradition. This skill treats a hard `t/d`-like `th` as 1 and otherwise asks the user to choose a consistent convention.
- Double consonants encode once when they make one sound: “mummy” is normally `m-m` (33), not four digits.
- Extra encoded consonants invalidate an exact peg even when the first two sounds match. A user may keep a non-exact personal mapping only after explicitly acknowledging it.

## Quiz Evaluation

Accept equivalent sounds within a digit group. For two-digit items, order matters. A response such as `34 = r-m` fails even though both sounds are present.

After two failed attempts, point to the digit's memory cue and ask a new item using that digit. Do not answer the remaining quiz for the user.
